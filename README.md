## 💡 About the Project

The goal of this project was to replicate Google’s iconic homepage with absolute precision while modernizing its underlying layout engine. 

By leveraging native CSS capabilities, this clone adapts dynamically to any device environment. It automatically senses whether a visitor's device is set to light or dark mode, updating the entire UI theme instantly without requiring a manual toggle button. It represents a deep dive into clean layout structure, asset alignment, and clean front-end design systems.

---

## ✨ Project Highlights

* **Pure Semantic Markup:** Built completely using standard HTML5 tags for clean document structure and accessibility.
* **Fluid Flexbox Layouts:** Uses flexible box modeling to perfectly center components and maintain proportions when browser windows resize.
* **System-Aware Dark Mode:** Natively integrates with user system settings, shifting seamlessly between crisp light and modern dark profiles on the fly.
* **Granular Screen Scaling:** Custom-tailored media queries guarantee that elements like the search bar, navigation links, and footer links stay perfectly proportioned across all screen boundaries—from tiny smartphones to ultrawide monitors.
* **Zero Dependencies:** Completely free of heavy libraries, web frameworks, or external script trackers for instant page loads.
